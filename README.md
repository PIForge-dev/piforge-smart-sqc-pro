## Key Features

- **Statistical Calculations**: Auto-calculates Mean, Standard Deviation (Sigma), Upper/Lower Control Limits (UCL/LCL).
- **Nelson & Western Electric Rules**: Real-time detection and color highlight of 8 standard SQC rule violations.
- **Interactive Rule Toggle**: Turn individual rule checks on/off directly from the chart configuration.
- **Custom Time Range support**: Analyze historical process trends with rolling statistical baselines.
